# 谢思宇 · Siyu Xie — Personal Homepage

一个零依赖的静态个人主页，围绕 `About / Research / Intern / Projects` 四个主栏目展开。

入口新增全屏二进制人物封面：页面加载时从透明人物原图采样颜色，以紧密的随机 `0 / 1` 字符逐步聚合成目标图像；眼睛与嘴部使用分层蓝灰色字符维持结构与对比。指针移动时，圆形镜片会切换成深色网格中的完整像素机器人半身，并以轻微视差跟随镜片，形成“人物表面 / 机器人内部”的反差效果。向下滚动会通过粘滞场景与同步交叉渐变把封面过渡到真正的个人主页，并在越过阈值后吸附到完整主页。封面同时提供 `welcome` 对话框、高对比 `SCROLL TO VIEW` 下箭头引导、减少动态效果偏好适配，以及 Canvas 不可用时的静态回退图。

视觉上采用“秋招雷达”的冷白浅蓝背景、状态信号与编号信息卡；结构上参考 setsaile 的左侧个人档案栏和右侧学术内容区。Intern 呈现蚂蚁集团多模态 Memory 算法实习，聚焦长周期、多会话、多模态的用户理解记忆系统，按“项目概览 / 实习流程事项”展开，只保留可公开的链路级信息，不出现内部项目名与仓库链接；Projects 保留 Geek Mind 具身 Agent 平台与操作中构建记忆系统两个同级案例。

## 本地预览

在项目目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

## 部署

站点无需构建步骤。GitHub Pages 从仓库根目录发布；腾讯云 EdgeOne 可上传 `dist/` 文件夹或 `siyu-xie-homepage.zip`，并确保 `index.html` 位于上传根目录。

请勿上传整个工作目录：简历 PDF、原始视频、GIF 和参考链接文件仅作为本地素材，其中简历包含不适合直接公开的个人信息。

如需长期稳定的中国大陆访问地址，请在腾讯云 EdgeOne Pages 选择包含中国大陆的加速区域，并绑定已完成 ICP 备案的自定义域名。
