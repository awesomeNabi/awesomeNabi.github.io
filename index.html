Language-Grounded Decoupled Action Representation for Robotic Manipulation

研究问题 连续机器人动作很难承载稳定、可解释的语义，也难以在任务间复用。

该工作以语言作为视觉理解与低层控制之间的语义桥梁，将连续动作解耦为平移、旋转与夹爪原语， 并通过语义引导的软标签对比学习，让相近动作在表征空间中保持可解释的结构。

方法

语言引导的动作解耦

训练目标

语义引导的软标签对比学习

结果

更强的跨任务动作泛化能力

VLM-Guided State-Aware Visual Representation Enhancement for Robotic Manipulation

研究问题 通用视觉表征能“看见”场景，却常常忽略机器人执行任务时真正关键的物理状态变化。

该工作从冻结 VLM 中蒸馏任务条件下的时序语义，同时加入末端执行器、关节与夹爪状态约束， 在 DROID 约 36K 条机器人轨迹上学习与操作过程一致的状态感知表征；部署时不再依赖 VLM。

方法

冻结 VLM 语义教师 + 机器人状态物理约束

训练目标

对齐任务条件下的帧间语义关系与连续状态变化

结果

15 / 17 项任务最优或并列最优，并完成 Franka 真机验证

01 / PROJECT OVERVIEW

项目概览

在线链路保持轻量，记忆建模异步完成，检索按独立契约回流。

01ONLINE低延迟接入
  1. INPUT 群聊事件接入 入参校验与上下文封装，接收系统层归一化后的消息内容。
  2. STM 短时缓冲与触发 带身份与时间元数据的原文写入短时记忆，按消息量或空闲时间触发。
02WORKER事实记忆建模
  1. LOAD 消息单元恢复 后台还原原始消息单元与运行上下文，进入异步处理阶段。
  2. STRUCTURE 轮次合并与话题聚类 将连续消息合并为轮次，并组织为可建模的话题单元。
  3. MODEL 结构化事实抽取 LLM 抽取事实，完成主体解析、规范化与最小有效性检查。
  4. WRITE 记忆决策与落库 相似召回后进入 ADD / NOOP 决策，去重后写入长期向量记忆。
03SEARCH上下文回流
  1. QUERY 检索意图与事实主体 解析检索意图与事实主体，形成结构化检索请求。
  2. RECALL 多路召回 向量、BM25 与分类等通道并行召回候选。
  3. RANK 融合重排 融合去重、软时间过滤与重排后，将相关记忆输出给 Agent。

02 / WORK ITEMS

个人工作与技术要点

重点参与图文记忆构建、多主体归因，以及 Add–Search 联调与评测。

A

MULTIMODAL REPRESENTATION

图像与对话联合编码

使用 GME 联合编码图片像素、Caption 与当轮对话，生成兼具视觉内容和会话语义的融合向量，让同一张图片能够被放回具体语境中理解。

Image pixels · Caption · Conversation · GME
B

CONTEXT & PROVENANCE

属性补充与来源关联

结合图片前后各 3 轮对话提取 ATTRS 属性，补充对象身份、类别与专有名称；以 Image ID 关联图片、描述、属性和来源对话，连接视觉记录与结构化事件。

Context window · ATTRS · Image ID
C

MULTI-SUBJECT ATTRIBUTION

区分“谁说的”与“谁的事实”

结合会话隔离、主体注册、别名与称谓归一，分开建模消息来源和事实归属；在写入、查询两侧施加身份约束，减少跨会话串记忆与多人事实混淆。

Session scope · Subject registry · Identity constraints
D

ADD–SEARCH INTEGRATION

联调、检索与可追溯问答

参与写入、记忆构建、检索和问答链路的联调与评测，结合向量 / BM25 混合检索及主体、时间约束返回相关记忆；接入手表、手环、体脂秤等 IoT 数据，支持长期习惯画像。

Hybrid retrieval · Time constraints · Evaluation

项目介绍

面向机械臂、四足机器人与轮式平台，构建配置驱动、插件化的跨本体 Agent Runtime， 将多模态感知、任务规划、工具调用与执行反馈组织为共享的任务闭环。

个人负责多模态感知、任务规划、工具调用和执行框架。通过统一语义上下文与本体能力适配， 解耦高层任务决策和底层硬件执行，支持导览、巡检及导航—抓取—递送等多步任务。

共享任务闭环

以 Observe → Fuse → Plan → Execute → Verify 组织任务闭环： 语音、文本、视觉与机器人状态进入共享上下文，Cortex 选择工具，由本体连接器执行， 再将执行结果回注下一轮决策。真实机器人与仿真环境复用同一高层任务循环。

MY ROLE

主要职责

A
插件化输入与本体适配

真机执行边界
