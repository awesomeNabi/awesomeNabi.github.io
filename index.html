Language-Grounded Decoupled Action Representation for Robotic Manipulation

研究问题 连续机器人动作很难承载稳定、可解释的语义，也难以在任务间复用。

该工作以语言作为视觉理解与低层控制之间的语义桥梁，将连续动作解耦为平移、旋转与夹爪原语， 并通过语义引导的软标签对比学习，让相近动作在表征空间中保持可解释的结构。

方法

语言引导的动作解耦

训练目标

语义引导的软标签对比学习

结果

更强的跨任务动作泛化能力

VLM-Guided State-Aware Visual Representation Pretraining for Robot Manipulation

研究问题 通用视觉表征能“看见”场景，却常常忽略机器人执行任务时真正关键的物理状态变化。

该工作从冻结 VLM 中蒸馏任务条件下的时序语义，同时加入末端执行器、关节与夹爪状态约束， 在 DROID 约 36K 条机器人轨迹上学习与操作过程一致的状态感知表征；部署时不再依赖 VLM。

方法

冻结 VLM 语义教师 + 机器人状态物理约束

训练目标

对齐任务条件下的帧间语义关系与连续状态变化

结果

15 / 17 项任务最优或并列最优，并完成 Franka 真机验证

长周期、多会话、多模态用户理解记忆系统

面向家庭健康助手、医疗群聊等场景，把持续产生的多主体群聊沉淀为结构化长期事实， 通过统一的 add / search 全链路，为上层 Agent 提供可写入、可检索的个性化上下文。

在线路径只完成入参校验、上下文封装与短时记忆缓冲；达到触发条件后，异步 worker 再执行 轮次合并、话题聚类、结构化事实抽取、记忆决策与统一写入。检索侧通过多路召回、融合去重与重排， 将相关记忆交还给上层 Agent。

01 / PROJECT OVERVIEW

项目概览

在线链路保持轻量，记忆建模异步完成，检索按独立契约回流。

01ONLINE低延迟接入
  1. INPUT 群聊事件接入 入参校验与上下文封装，接收系统层归一化后的消息内容。
  2. STM 短时缓冲与触发 带身份与时间元数据的原文写入短时记忆，按消息量或空闲时间触发。
02WORKER事实记忆建模
  1. LOAD 消息单元恢复 后台还原原始消息单元与运行上下文，进入异步处理阶段。
  2. STRUCTURE 轮次合并与话题聚类 将连续消息合并为轮次，并组织为可建模的话题单元。
  3. MODEL 结构化事实抽取 LLM 抽取事实，完成主体解析、规范化与最小有效性检查。
  4. WRITE 记忆决策与落库 相似召回后进入 ADD / NOOP 决策，去重后写入长期向量记忆。
03SEARCH上下文回流
  1. QUERY 检索意图与事实主体 解析检索意图与事实主体，形成结构化检索请求。
  2. RECALL 多路召回 向量、BM25 与分类等通道并行召回候选。
  3. RANK 融合重排 融合去重、软时间过滤与重排后，将相关记忆输出给 Agent。

PROJECT / 01 · 2026.03—2026.07

Geek Mind — 跨本体具身 Agent Runtime

上海码极客人工智能科技有限公司 · 核心框架研发

REAL-ROBOT DEPLOYED

项目介绍

面向机械臂与四足机器人，构建“多模态感知—LLM 决策—动作执行”的模块化 Agent 平台， 把感知、记忆、规划与机器人控制统一封装为可调用服务。

目标是在硬件协议碎片化、云边端协同与长程任务规划之间建立稳定接口， 让同一套上层智能体逻辑能够连接不同机器人本体，并完成自主任务闭环。

  • ROS2
  • Zenoh
  • MCP / HTTP
  • Function Calling
  • Planner LLM
  • Jetson
项目简介

Geek Mind 定义为面向机器人的“通用具身大脑”，以四大并行系统与中央事件总线 组织感知、交互、思考与动作，并通过硬件抽象层将不同机器人本体映射为标准语义指令， 使同一套上层智能体能力可以跨本体组合与执行。

PROJECT / 02 · 2026.02—2026.06

操作中构建记忆系统

第一视角语义空间记忆构建与 VLN/VLA 增强 · 视觉编码器预训练与表征增强

AAAI 2027 · UNDER REVIEW
第一视角操作 · 语义空间记忆真机演示
项目概述

连续操作中的视觉流不仅要记录“看见了什么”，还要持续组织物体、空间关系、可达性与状态变化。 项目以 object-centric spatial memory 将这些信息维护为可更新、可检索的长期环境上下文。

项目介绍

面向桌面机械臂构建 object-centric spatial memory，把瞬时第一视角观察组织为 可持续更新、可检索的语义空间记忆，为后续 VLN/VLA 策略提供长期环境上下文。

项目用冻结 VLM 提供任务条件下的高层语义监督，再结合机器人本体状态建立连续物理约束； 最终语义被压缩进轻量视觉编码器，部署阶段无需再调用 VLM。

  • Object-centric Memory
  • DROID
  • VLM Distillation
  • State-aware Pretraining
  • Franka
  • VLN / VLA
01

MY CONTRIBUTION

从记忆系统到任务视觉编码器

项目构建面向机器人连续观察的语义空间记忆；我负责其中的视觉编码器预训练与表征增强， 让记忆系统获得稳定、任务相关且可在真机高效部署的视觉特征。

01 · SYSTEM NEED
记忆系统需要什么

从连续第一视角中识别任务相关物体、关系与状态变化，为 grounding、关系建模和记忆更新提供依据。

02 · MY METHOD
我如何训练编码器

用冻结 VLM 蒸馏指令条件下的帧间语义关系，并加入末端、关节与夹爪状态约束，学习任务与物理状态一致的表征。

03 · SYSTEM VALUE
为记忆系统提供什么

输出可部署的 task-centric、state-aware 特征，支撑物体定位、关系更新与检索；部署阶段无需再次调用 VLM。
