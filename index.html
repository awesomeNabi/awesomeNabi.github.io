我负责什么

TREEMEM · 分层多模态记忆与检索模块 · 方法示意↗

蚂蚁集团实习 · 健康助手 / 多模态 Memory

长期记忆引擎 From dialogue to lasting context.

面向家庭健康助手与多主体群聊，构建带身份、时间与来源约束的长期上下文。TreeMem 是引擎中的分层多模态记忆与检索模块，组织会话、事件与原始对话，为 Add–Search 链路提供可追溯的记忆。

  • Add / Search
  • TreeMem / Session Tree
  • 多主体归因
  • GME
项目档案 ＋

系统与模块

长期记忆引擎承接跨会话、多主体的图文消息，支撑个性化问答和历史信息追溯。TreeMem 是其中的记忆组织与检索模块：以 Session Tree 保留结构化事件和无损原始轮次，在检索效率与信息完整性之间建立联系。

TreeMem · 分层多模态记忆与检索

  1. 两层检索：按主题选取会话，再在会话内检索事件。
  2. 证据修复：事件无法支撑回答时，展开关联的原始轮次，恢复摘要中遗漏的信息。
  3. 统一图文空间：GME 联合编码图像、Caption 与对话上下文，支持跨会话视觉检索。
  4. 语境属性：利用图片前后各 3 轮对话提取 ATTRS，补充 Caption 中遗漏的对象身份、类别与专有名称；通过 Image ID 连接图片、属性与来源对话。

个人工作与工程落地

  1. 多模态记忆：参与图文记忆构建，让视觉记录与结构化事件保持关联。
  2. 多主体归因：结合会话隔离、主体注册、别名与称谓归一，将消息来源与事实归属分别建模，在写入、查询侧施加身份约束。
  3. Add–Search 联调：参与带身份、时间条件的检索评测，以及家庭健康群、医疗群聊和 IoT 数据接入场景联调。

空间感知 · 对象与关系

三维语义场景图 A world of objects.

从带位姿的 RGB-D 序列出发，将多视角观测关联为世界坐标下的物体，进一步建立属性、功能与位置关系，让环境可以被结构化查询。

  • BoxFusion / CuTR
  • OpenCLIP
  • Qwen
项目档案 ＋

个人贡献

负责跨帧对象绑定与富语义对象构建：结合世界坐标三维框的 3D IoU、小物体二维重投影匹配，关联实例、历史观测与语义属性。

几何到语义

基于 BoxFusion、CuTR 与 OpenCLIP 等上游工作组织感知流程，通过 Qwen 生成颜色、材质、部件、状态及功能描述，输出对象属性和关系三元组。

当前边界

在线路径显示和更新三维框，完整属性及关系图离线生成。实例编号可能切换；历史输出包含误检与关系错误。该项目尚未接入由场景图驱动的导航、抓取闭环。
